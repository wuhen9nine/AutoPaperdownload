AutoPaperdownload
一个基于 Python 的学术论文自动搜索与下载工具。

📖 项目简介
AutoPaperdownload 旨在帮助研究人员和学生通过自动化脚本，通过关键词检索或预先准备好的文献doi号，快速从学术资源库检索并下载所需的文献。该项目利用 Selenium 等自动化技术模拟浏览器操作，从而绕过繁琐的手动搜索过程。

✨ 主要功能
关键词搜索：支持根据用户提供的关键词列表进行批量检索相关文献。

自动化下载：根据doi号，自动将文献下载至本地。

支持多平台：主要针对主流学术数据库，可针对具体领域自由添加。

人机验证跳过：通过模拟人的行为以绕开人机验证，完成下载

🛠️ 环境要求
在运行脚本之前，请确保您的环境中已安装以下组件：

Python 3.x

edge浏览器（其他浏览器兼容性没有经过验证，且需修改相关配置）

WebDriver：与浏览器版本匹配的驱动程序

📂 使用说明
🛠 核心组件库
该系统由以下核心脚本协同工作：

getdoi_helper.py (PubMed 调度): 负责根据关键词在 PubMed 上检索并获取初始 DOI 列表。

Paperdownload.py (正文下载): 核心下载引擎，支持多域名、多规则。

SIdownload.py (补充材料下载): 专门抓取论文的 Supporting Information。

筛选文件大小.py (清理工具): 自动识别并剔除下载失败的“空壳”文件或损坏的文献文件。

Csv_Turner_strenth.py (失败分析): 从下载记录中精准提取 Failed 状态的 DOI，便于二次重试。

doiexacter.py (文档提取): 支持从本地 RSS 订阅文件或 TXT 文档中直接提取严格格式的 DOI，并转换为标准格式的csv文件。

🚀运行方式
直接运行主管理程序：
python config_manager.py

配置参数: 在“脚本内部参数管理”标签页设置与文献下载有关的参数。

添加规则: 如果遇到新网站，使用“域名规则向导”三步走：输入 URL -> 确认下载方式 -> 自动保存规则。


从零开始流程：
  提示词启动：1.在“脚本内部参数管理”标签页输入关键词，保存
             2.返回“任务执行页面”，点击 🚀 启动全自动下载流程
             注：当前支持在pubmed网站上进行检索，且单次只能下载最新的15篇文献
  文献信息文档启动：1.在“脚本内部参数管理”中输入初始文档路径
                  2.运行”指定文档DOI提取“
